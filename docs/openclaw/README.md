# OpenClaw 操作指南

本目录用于给 OpenClaw 或其他网页代理提供可直接阅读的 OMS 操作说明。

目标：
- 让代理知道不同角色应该进入哪些菜单
- 让代理知道每类任务的标准步骤、成功标志和停止条件
- 避免代理误操作高风险页面

阅读顺序建议：
1. `01-角色与权限总览.md`
2. `02-菜单与页面地图.md`
3. `03-角色操作剧本.md`
4. `04-异常处理与停止条件.md`
5. `90-验证码IP白名单设计.md`

使用约定：
- 先确认当前登录账号的角色、权限和公司抬头
- 先通过“菜单与页面地图”识别当前页面，再执行剧本
- 如果页面文案与本手册不一致，优先以页面实际文案为准
- 遇到“无权限”“金额不一致”“主体不一致”“数据缺失”等提示时，不要硬提交流程

高风险动作：
- 删除数据
- 覆盖合同编号
- 修改发票号、回款状态、付款状态
- 生成合同、生成采购/销售对账单

这些动作必须先满足剧本中的前置条件，再执行。
