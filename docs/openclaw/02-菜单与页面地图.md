# 菜单与页面地图

## 主导航

### 首页
- 菜单：`首页`
- 页面特征：
  - Dashboard 卡片
  - “待办事宜”“采销数据”页签
  - 待指派、待发货、待回款等卡片

### 我的商品
- 菜单：`我的商品`
- 页面特征：
  - 商品列表
  - 常见按钮：新增商品、批量导入、导出商品

### 商机
- 菜单：`商机`
- 子页面：
  - 商机列表
  - 报价模板

### 销售管理
- 菜单：`销售管理`
- 子页面：
  - 销售订单
  - 销售对账
  - 销项
  - 销售结算
  - 链路观察
- 页面特征：
  - 销售订单页常见按钮：指派、结算、上传、修改
  - 结算弹窗字段：发票号码、开票日期、发票上传、甲方对账单号、结算单号

### 采购管理
- 菜单：`采购管理`
- 子页面：
  - 采购订单
  - 采购对账
  - 进项
  - 采购结算
- 页面特征：
  - 常见按钮：指派、转派、生成合同、生成采购对账单、发起付款申请

### 合作管理
- 菜单：`合作管理`
- 子页面：
  - 合同
  - 合同模板
  - 用户信息维护
  - 甲方回款规则
  - 手工归组（部分账号/公司可见）

### 平台授权
- 菜单：`平台授权`
- 子页面：
  - 授权统计
  - 扫码追踪

### 用户管理
- 菜单：`用户管理`
- 子页面：
  - 用户列表
  - 隐私访问记录

## 关键页面识别特征

### 登录页
- 标题：`飞础科(FOTRIC)OMS 订单管理系统`
- 输入框：用户名、密码、验证码
- 按钮：登录、刷新验证码

### 销售结算弹窗
- 常见字段：
  - 甲方对账单号
  - 发票号码
  - 开票日期
  - 发票上传
  - 结算单号
  - 甲方回款状态
- 新增特征：
  - 发票识别结果
  - 购买方 / 销售方
  - 与订单一致 / 与订单不一致

### 采购指派 / 生成合同弹窗
- 常见字段：
  - 交付方（乙方）
  - 乙方业务员
  - 线下销售
  - 扣点(%)
  - 交付方采购价
  - 账期
  - 合同编号
  - 合同模板
- 常见按钮：
  - 生成合同
  - 生成合同并转派

## OpenClaw 页面识别规则

进入页面后优先确认：
1. 面包屑或菜单高亮是否正确
2. 页面标题或弹窗标题是否正确
3. 是否存在该剧本要求的字段和按钮
4. 是否出现“无权限”“请联系管理员”等提示

如果页面缺少关键字段，不要继续执行，先判断：
- 是否进入了错误菜单
- 是否用了错误账号
- 是否当前订单状态不支持该操作
