# 角色与权限总览

## 账号角色

系统当前可见的角色类型：

| 代码 | 常见展示 |
|---|---|
| `ROLE_ADMIN` | 管理员 |
| `ROLE_ECOMMERCE` | 工业电商 / 电商 / 甲方 |
| `ROLE_XIAOAN` | 小安智能 |
| `ROLE_FACTORY` | 工厂 |
| `ROLE_DELIVERY` | 交付方 |
| `ROLE_SHIPPING` | 出货方 |
| `ROLE_WAREHOUSE` | 仓库 |

补充说明：
- `username=admin` 在前端通常按超级管理员处理
- 很多页面是否可见，不只取决于 `role`，还取决于 `permissions`

## 常见权限点

模块级权限：
- `dashboard`
- `product`
- `opportunity`
- `sales`
- `purchase`
- `warehouse`
- `settlement`
- `cooperation`
- `user`
- `authorization`

细粒度权限：
- `settlement_sales`：销售结算中的甲方对账单号、结算单号维护
- `settlement_finance`：销售结算中的发票号、发票上传、回款状态维护
- `platform_refund`：甲方回款状态维护
- `purchase_payment_apply`：采购付款申请
- `purchase_payment_finance`：采购财务打款与凭证
- `purchase_invoice_track`：采购进项发票跟进
- `sales_all_orders`：商务查看/处理更多销售订单
- `contract_full_rx_feichuke`、`sales_feichuke_contract`：合同相关扩展权限
- `purchase_payment_view_all`：采购付款申请全量查看
- `authorization`：平台授权统计与扫码追踪

## 角色建议高频任务

### 管理员
- 配置用户、角色与权限
- 检查全局异常页面
- 处理合同或跨模块异常
- 管理合作信息、模板、授权配置

### 电商 / 甲方
- 销售订单查询与跟进
- 销售对账与销售结算
- 商机与报价模板
- 查看 Dashboard 待办

### 仓库
- 查看销售订单物流信息
- 发货、签收单相关操作
- 跟踪母单物流与回单状态

### 财务类账号
- 销项发票、进项发票处理
- 销售结算中的发票与回款维护
- 采购付款与凭证处理

### 交付方 / 工厂 / 出货方
- 采购列表中的指派、转派、合同生成
- 交付方采购价、账期、合同模板维护
- 第三方订单的线下销售信息补充

## OpenClaw 使用前必须确认

每次登录后先确认：
1. 当前用户名
2. 当前角色
3. 当前公司抬头
4. 当前菜单是否与该角色匹配
5. 是否拥有执行该任务的细粒度权限

如果菜单缺失或按钮不出现，不要猜测流程，先停止并反馈“账号权限不足或角色不匹配”。
