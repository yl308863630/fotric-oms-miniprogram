# 角色操作剧本

本文件给 OpenClaw 提供“按任务执行”的标准步骤。

格式约定：
- 前置条件：不满足就停止
- 操作步骤：按顺序执行
- 成功判定：看到这些结果才算完成
- 停止条件：出现这些情况不要继续

## 剧本 1：财务录入发票并保存销售结算

- 适用角色：管理员、具备 `settlement_finance` 或 `platform_refund` 的财务类账号
- 入口：`销售管理 -> 销售订单`，行内点击 `结算`
- 前置条件：
  - 订单允许进入结算弹窗
  - 有发票文件
- 操作步骤：
  1. 打开结算弹窗
  2. 上传发票
  3. 等待系统回填发票号码、开票日期
  4. 查看“发票识别结果”
  5. 核对购买方、销售方是否与订单一致
  6. 必要时填写或修正发票号码、开票日期
  7. 保存结算
- 成功判定：
  - 页面提示 `结算信息保存成功`
- 停止条件：
  - 发票号重复
  - 购买方/销售方与订单不一致且无法人工确认
  - 没有财务权限

## 剧本 2：销售补充甲方对账单号 / 结算单号

- 适用角色：管理员、具备 `settlement_sales` 的账号
- 入口：`销售管理 -> 销售订单 -> 结算`
- 前置条件：
  - 可见结算弹窗中的对应字段
- 操作步骤：
  1. 打开结算弹窗
  2. 查看 `甲方对账单号`
  3. 查看 `结算单号`
  4. 如为空，先判断是否应由系统后续自动生成
  5. 只有在业务明确要求人工填写时再输入
- 成功判定：
  - 页面提示保存成功
- 停止条件：
  - 不确定是否应人工覆盖
  - 当前账号不是销售结算维护权限

## 剧本 3：采购指派并生成合同

- 适用角色：管理员、采购/交付相关账号
- 入口：`采购管理 -> 采购订单`，选择记录后进入指派/生成合同弹窗
- 前置条件：
  - 已选择合同模板
  - 已选择交付方（乙方）
  - 第三方订单且乙方为上海热像科技股份有限公司时，已填写 `线下销售`
- 操作步骤：
  1. 选择交付方（乙方）
  2. 核对乙方业务员
  3. 如有 `线下销售` 卡片，补充线下销售姓名
  4. 核对 `交付方采购价`
  5. 选择或填写 `账期`
  6. 检查 `合同编号`
  7. 选择 `合同模板`
  8. 点击 `生成合同` 或 `生成合同并转派`
- 成功判定：
  - 页面提示 `合同生成成功` 或 `合并指派成功`
- 停止条件：
  - 合同模板为空
  - 第三方订单必须填写线下销售但未填写
  - 采购价、账期明显错误

## 剧本 4：仓库查看销售单并处理物流

- 适用角色：仓库
- 入口：`销售管理 -> 销售订单`
- 前置条件：
  - 账号为仓库或具备仓库相关权限
- 操作步骤：
  1. 使用筛选定位订单
  2. 查看物流单号、签收单状态、发货要求
  3. 根据页面可见按钮执行发货/上传签收单等动作
- 成功判定：
  - 对应物流或签收信息更新成功
- 停止条件：
  - 页面没有相关按钮
  - 当前订单状态不允许继续

## 剧本 5：管理员维护用户与权限

- 适用角色：管理员
- 入口：`用户管理 -> 用户列表`
- 前置条件：
  - 当前账号为管理员
- 操作步骤：
  1. 搜索目标用户
  2. 检查角色
  3. 检查权限勾选
  4. 保存修改
- 成功判定：
  - 用户保存成功
- 停止条件：
  - 不清楚该用户应具备哪些权限
  - 涉及全局安全设置但页面实际是普通用户编辑

## OpenClaw 执行规则

- 先读当前角色对应剧本，再开始点击
- 每一步都要确认按钮文案和字段文案一致
- 不要跨角色猜测操作
- 遇到删除、覆盖、生成类动作，执行前再确认一次页面标题和当前订单编号
