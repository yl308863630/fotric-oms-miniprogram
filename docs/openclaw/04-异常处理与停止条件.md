# 异常处理与停止条件

本文件用于约束 OpenClaw 在异常场景下的行为。

## 通用原则

- 遇到不确定页面，不继续点“确认”“提交”“生成”
- 遇到权限提示，不尝试绕过
- 遇到金额、主体、账号不一致，不继续保存
- 允许查看、截图、记录；不允许猜测业务含义后提交

## 常见异常

### 1. 无权限

常见文案：
- `无权限`
- `请联系管理员`
- 页面空白但按钮缺失

处理：
- 停止当前任务
- 记录当前账号、角色、菜单名
- 反馈“当前账号缺少权限”

### 2. 验证码出现

处理：
- 如果已启用 IP 开白且仍出现验证码，反馈“白名单未生效或账号不在允许范围”
- 不要自行多次试错验证码

### 3. 发票 OCR 提示不一致

常见场景：
- 购买方不一致
- 销售方不一致
- 发票号重复

处理：
- 先查看发票识别结果卡片
- 若主体不一致且无法由业务确认，停止保存
- 若仅缺少某字段，可提示人工核对

### 4. 第三方订单缺少线下销售

处理：
- 如果页面出现线下销售卡片且为空，不要继续生成合同
- 反馈“需要先填写线下销售姓名”

### 5. 合同模板为空

处理：
- 不要继续点生成合同
- 返回并要求补充模板

### 6. 金额核对异常

处理：
- 若采购价、销售价、数量明显不匹配，停止
- 不要为了完成任务随意改价

## 必须停止的高风险场景

- 要删除记录，但剧本未明确允许
- 要覆盖合同编号，但用户未明确要求
- 要改发票号、回款状态、付款状态，但缺少对应权限
- 页面字段与手册差异过大，无法确认是不是同一流程

2. 当前角色/账号：
3. 已完成步骤：

这样便于人工接手。
