# 顺丰快递物流联调步骤（在线环境）

用**在线环境**（本机前后端 + 可选 ngrok）联调顺丰接口，验证单号 **SF5122068084664** 能否获取到最新物流节点。

---

## 一、准备在线环境

1. **启动后端**（若未启动）
   - 终端进入：`cd oms-backend`
   - 执行：`mvn spring-boot:run`
   - 看到 `Started ... Application`、Tomcat 在 **8080** 即成功。

2. **启动前端**（若未启动）
   - 新终端进入：`cd oms-frontend`
   - 执行：`npm run dev`
   - 看到 `Local: http://localhost:3000` 即成功。

3. **（可选）外网访问**
   - 若需用手机或别的电脑访问：在终端执行 `ngrok http 3000`，用生成的 `https://xxx.ngrok-free.app` 访问。
   - **只暴露 3000，不要暴露 8080**（接口会经 Vite 代理到本机 8080）。

---

## 二、在系统里查顺丰单号 SF5122068084664

### 方式 A：订单列表里已有该单号（推荐）

1. 浏览器打开：**http://localhost:3000**（或你的 ngrok 外网地址）。
2. 登录（如 `sonmin` / `Sm123456`）。
3. 进入 **销售管理** → **订单**（订单列表）。
4. 在列表中找到 **物流单号** 为 **SF5122068084664** 的订单。
   - 若列表没有「物流单号」列：点表头右侧 **列设置**，勾选 **物流单号** 并确定。
5. 点击该订单行的 **物流单号**（蓝色链接 **SF5122068084664**）。
6. 会弹出 **「快递物流信息」** 对话框，系统会请求顺丰接口并展示轨迹。
7. 查看是否展示**最新物流节点**；可点对话框内 **「刷新」** 再次拉取。

### 方式 B：列表里没有这个单号

1. 先让某条订单带上顺丰 + 单号 **SF5122068084664**：
   - 在订单列表找到一条「已发货」或可发货的订单，点 **操作** → **发货**；
   - 在发货弹窗中：**物流公司** 选 **顺丰速运**，**物流单号** 填 **SF5122068084664**，保存。
2. 保存后回到订单列表，该订单的 **物流单号** 列会显示 **SF5122068084664**。
3. 再按 **方式 A** 的 5～7 步：点击该单号 → 打开「快递物流信息」→ 查看/刷新轨迹。

---

## 三、接口说明（便于排查）

- 前端点击物流单号后，会请求：
  - **GET** `/api/logistics/query?company=顺丰速运&trackingNumber=SF5122068084664`
- 后端会识别「顺丰速运」或「顺丰」，调用顺丰官方 API（`KuaiDi100Config` 中配置的 `sfApiUrl` 等）拉取路由并返回轨迹。
- 物流公司名必须是 **顺丰速运** 或 **顺丰**，才能走顺丰接口；其它公司走快递100或京东等。

---

## 四、顺丰必传参数：收件人手机号后四位

顺丰路由查询接口要求传 **checkPhoneNo**（收件人手机号后四位），否则会报 **A1001 必传参数不可为空**。

- 从**订单列表**点「物流单号」打开物流时，系统会自动带上传单订单的**收货人电话后四位**。
- 若订单未填收货人电话或顺丰仍报错，可在发货/订单里补全**收货人电话**，保存后再查物流；或联系管理员在配置中核对顺丰沙箱/生产环境是否要求其它参数。

## 五、若拿不到最新节点或报错

1. **看浏览器**
   - F12 → **Network**：找到 `logistics/query` 请求，看状态码和响应 body 里的 `isSuccess`、`message`。

2. **看后端日志**
   - 控制台会有 `顺丰API响应` 或 `顺丰查询失败` 等日志，根据错误码/错误信息排查。

3. **常见情况**
   - **A1001 必传参数不可为空**：多为未传 `checkPhoneNo`，已改为自动带订单收货人电话后四位，请确认该订单已填**收货人电话**。
   - **单号不存在或已过期**：顺丰侧可能返回失败或空轨迹。
   - **顺丰 API 配置**：检查 `application.yml` 或配置类里 `kuaidi100.sfAppKey`、`kuaidi100.sfAppSecret`、`kuaidi100.sfApiUrl`（生产/沙箱是否与当前环境一致）。
   - **网络**：本机或服务器要能访问顺丰 API 地址（如 `https://sfapi.sf-express.com`）。

## 五、小结

| 步骤 | 做什么 |
|------|--------|
| 1 | 本机启动后端(8080)、前端(3000)，可选 ngrok 暴露 3000 |
| 2 | 浏览器打开前端地址并登录 |
| 3 | 销售管理 → 订单 → 找到物流单号为 SF5122068084664 的订单（没有则先发货填写该单号） |
| 4 | 点击该单号 → 打开「快递物流信息」→ 查看/刷新，确认是否拿到最新物流节点 |

按以上顺序操作即可在在线环境下联调顺丰，并验证 SF5122068084664 的物流节点是否正常返回。
