# 钉钉机器人消息通知使用说明

## 功能介绍

系统已集成钉钉机器人消息通知功能，可以在以下场景发送通知：
- 新订单创建
- 物流状态更新
- 库存预警
- 自定义消息

## 配置步骤

### 1. 在钉钉群中添加自定义机器人

1. 打开钉钉群聊
2. 点击群设置 → 智能群助手 → 添加机器人
3. 选择「自定义」机器人
4. 填写机器人名称（如：OMS订单通知）
5. 选择「加签」或「自定义关键词」安全设置
6. 点击「完成」，复制 Webhook 地址

### 2. 配置系统

编辑 `oms-backend/src/main/resources/application.yml`：

```yaml
dingtalk:
  # 启用钉钉机器人通知
  enabled: true
  # 钉钉机器人 Webhook 地址（从钉钉群获取）
  webhook-url: https://oapi.dingtalk.com/robot/send?access_token=你的access_token
  # 加签密钥（如果设置了加签）
  secret: "你的加签密钥"
```

### 3. 安全设置说明

#### 方式一：使用加签（推荐）
- 在钉钉机器人设置中选择「加签」
- 复制加签密钥，填写到配置文件的 `secret` 字段

#### 方式二：使用自定义关键词
- 在钉钉机器人设置中选择「自定义关键词」
- 添加关键词，例如：`订单`、`物流`、`库存`
- 发送的消息中必须包含这些关键词

## 使用方法

### 注入 DingTalkService

在需要发送通知的 Service 或 Controller 中注入：

```java
@Autowired
private DingTalkService dingTalkService;
```

### 发送文本消息

```java
dingTalkService.sendTextMessage("这是一条测试消息");
```

### 发送 Markdown 消息

```java
dingTalkService.sendMarkdownMessage(
    "标题", 
    "## 这是标题\n\n这是内容 **加粗**"
);
```

### 发送新订单通知

```java
dingTalkService.sendOrderNotification(
    "订单号",
    "客户名称",
    "商品名称",
    new BigDecimal("999.00")
);
```

### 发送物流更新通知

```java
dingTalkService.sendLogisticsNotification(
    "订单号",
    "物流单号",
    "已签收"
);
```

### 发送库存预警通知

```java
dingTalkService.sendStockWarning(
    "商品名称",
    "商品编码",
    5  // 当前库存
);
```

## 实际应用示例

### 在 SalesOrderService 中添加订单通知

```java
@Autowired
private DingTalkService dingTalkService;

@Transactional
public SalesOrder saveOrder(SalesOrder order) {
    SalesOrder savedOrder = salesOrderRepository.save(order);
    
    // 发送新订单通知
    dingTalkService.sendOrderNotification(
        savedOrder.getOmsOrderNo(),
        savedOrder.getFinalCustomerTitle(),
        savedOrder.getProductName(),
        savedOrder.getTaxIncludedTotal()
    );
    
    return savedOrder;
}
```

### 在 ProductService 中添加库存预警

```java
@Autowired
private DingTalkService dingTalkService;

@Transactional
public Product updateProduct(Long id, Product product) {
    Product existingProduct = productRepository.findById(id).orElse(null);
    if (existingProduct == null) return null;
    
    existingProduct.setStock(product.getStock());
    
    // 库存低于10时发送预警
    if (product.getStock() != null && product.getStock() < 10) {
        dingTalkService.sendStockWarning(
            existingProduct.getName(),
            existingProduct.getCode(),
            product.getStock()
        );
    }
    
    return productRepository.save(existingProduct);
}
```

## 注意事项

1. **测试环境**：建议在测试环境先测试，确认无误后再在生产环境启用
2. **消息频率**：钉钉机器人有消息频率限制，避免短时间内发送大量消息
3. **关键词**：如果使用自定义关键词，确保消息中包含至少一个关键词
4. **安全**：不要将 Webhook 地址和密钥提交到公开仓库

## 测试

可以创建一个测试接口来验证钉钉机器人配置：

```java
@RestController
@RequestMapping("/api/dingtalk")
public class DingTalkTestController {

    @Autowired
    private DingTalkService dingTalkService;

    @GetMapping("/test")
    public String test() {
        dingTalkService.sendTextMessage("✅ OMS 钉钉机器人测试成功！");
        return "测试消息已发送";
    }
}
```

访问：`http://localhost:8080/api/dingtalk/test` 即可测试。
